# BaiTapArray

Bài tập JavaScript Buổi 7-8 (CyberSoft) - Xử lý mảng.

🔗 **Demo:** [Link web deploy](https://baitaparray.vercel.app/)

## Danh sách bài tập

1. Tổng các số dương
2. Đếm số dương
3. Tìm số nhỏ nhất
4. Tìm số dương nhỏ nhất
5. Tìm số chẵn cuối cùng (không có trả về -1)
6. Đổi chỗ 2 giá trị theo vị trí
7. Sắp xếp tăng dần
8. Tìm số nguyên tố đầu tiên (không có trả về -1)
9. Đếm số nguyên trong mảng số thực
10. So sánh số lượng số dương và số âm

## Công nghệ

- HTML, JavaScript
- Tailwind CSS + Flowbite
